# liberadoPDF

Visor y presentador de PDF para Windows, portable, que reproduce las animaciones del paquete LaTeX `animate` igual que Adobe Acrobat Reader. Por dentro lleva el visor de pdf.js con su sandbox de JavaScript; liberadoPDF le añade la experiencia de presentación.

**Estado: en construcción** (entrega 1). Diseño en `docs/superpowers/specs/`, plan en `docs/superpowers/plans/`.
